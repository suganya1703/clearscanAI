# How to push this to GitHub (2 minutes)

1. Go to https://github.com/new and create a new repository named `clearscan-ai`
   (keep it Public, don't initialize with a README — this project already has one).

2. On your computer, unzip this folder, then open a terminal inside it and run:

```bash
git init
git add .
git commit -m "Initial commit: ClearScan AI - image restoration for semiconductor inspection"
git branch -M main
git remote add origin https://github.com/<your-username>/clearscan-ai.git
git push -u origin main
```

3. Copy the repo URL (e.g. `https://github.com/<your-username>/clearscan-ai`) and paste it
   into the "GitHub Repository" field in the idea submission deck/PDF.

That's it — your code is live and linkable.
